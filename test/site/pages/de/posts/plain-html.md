## Die Seite ist das Produkt

Eine statische Seite wartet auf nichts: kein Skript, keine Daten. Der Browser zeichnet, sobald das HTML ankommt.

## Weniger, das kaputtgehen kann

Jede Abhängigkeit, die Sie weglassen, müssen Sie nie aktualisieren.
